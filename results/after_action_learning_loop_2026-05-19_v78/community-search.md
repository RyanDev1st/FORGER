# community-after-action-learning-loop

Practitioner lane for After-Action Learning Loop.

## Input

Brief and `aar-ledger.md`.

## Mission

Turn practitioner failures, working habits, issue threads, repos, and process retrospectives into concrete sustain/improve actions.

## Selection rule

Prefer sources with:

- postmortems, retrospectives, incident reviews, or issue closures
- concrete changes with owners, deadlines, or follow-up tests
- working artifacts showing changed behavior
- implementation failures that explain what to avoid
- named teams, maintainers, or practitioners

## Finding format

```markdown
### Finding C<n>: <community review finding>
- Review id:
- Source:
- Verbatim quote: "<≤25 words>"
- Practice claim:
- What went well:
- What failed or could improve:
- Action item:
- Next-iteration test:
```

## Drop rules

Drop blame posts, vibe retrospectives, lessons with no action, and action items that cannot be checked in the next run.

## Closing

List sustained practices, improvement actions, failed habits, owner/test gaps, and reusable operational lessons.
