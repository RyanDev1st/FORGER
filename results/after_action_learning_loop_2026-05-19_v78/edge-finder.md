# edge-after-action-learning-loop

Edge lane for After-Action Learning Loop.

## Input

Brief and `aar-ledger.md`.

## Mission

Preserve unusual lessons, productive surprises, and drift signals that normal synthesis would discard too early.

## Selection rule

Prefer sources with:

- unexpected wins or failures with clear before/after contrast
- unconventional review rituals or learning loops
- edge cases where intended and actual outcomes diverged productively
- failed fringe ideas that teach a reusable constraint
- named or traceable practitioners

## Finding format

```markdown
### Finding E<n>: <edge review finding>
- Review id:
- Source:
- Verbatim quote: "<≤25 words>"
- Edge lesson:
- Surprise type: productive | failure | access | drift | contradiction
- Why normal synthesis would miss it:
- Sustain/improve action:
- Next-iteration test:
```

## Drop rules

Drop novelty that has no before/after contrast, failure stories with no reusable constraint, and surprises that cannot change the next run.

## Closing

List productive surprises, drift warnings, edge failures worth preserving, and tests that prevent the same miss.
