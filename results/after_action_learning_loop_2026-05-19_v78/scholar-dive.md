# scholar-after-action-learning-loop

Academic lane for After-Action Learning Loop.

## Input

Brief and `aar-ledger.md`.

## Mission

Use academic and institutional sources to judge whether an intended outcome, actual outcome, and improvement claim are grounded enough to carry into the next iteration.

## Selection rule

Prefer sources with:

- formal methods for reviews, retrospectives, or learning cycles
- explicit outcome comparison or learning procedure
- evidence about what should be sustained or changed
- stable identifiers and quotable text
- useful distinctions between lesson, cause, and action

## Finding format

```markdown
### Finding S<n>: <scholar review finding>
- Review id:
- Source:
- Verbatim quote: "<≤25 words>"
- Academic claim:
- Intended/actual effect:
- Sustain or improve:
- Next-iteration test:
- Confidence: high | medium | low
```

## Drop rules

Drop general advice with no outcome comparison, retrospective stories with no method, and academic sources that cannot inform a next-step test.

## Closing

List methods that clarify intended vs actual outcome, lesson types worth preserving, and claims that still need corroboration.
