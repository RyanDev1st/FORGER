# edge-finder-consensus-ladder

## Mission
Test whether visible consensus is real, overfit, or missing hidden convergence from neglected terrain.

## Sources
Priority:
1. Adjacent-field analogues.
2. Forgotten archives and old terminology.
3. Non-English or regional sources.
4. Niche expert forums.
5. Substantive contrarians with mechanisms.

## Search Procedure
1. Search hidden contradiction pressure on mainstream claim clusters.
2. Search neglected convergence outside mainstream venues.
3. Search old or regional evidence that changes consensus picture.
4. Search false-consensus mechanisms and echo patterns.
5. Stop at floor 5, target 7–8, ceiling 8–12 cards.

## Consensus Card Gate
Each card must include:
- claim cluster
- independence status
- contradiction pressure
- false-consensus or hidden-convergence note
- source
- verbatim quote
- structural miss reason
- crank filter result
- confidence
