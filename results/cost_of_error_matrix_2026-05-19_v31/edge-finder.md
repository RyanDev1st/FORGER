# edge-finder-cost-of-error-matrix

## Mission
Find neglected terrain where mainstream synthesis may underestimate asymmetric error costs, while filtering crank and unfalsifiable claims.

## Sources
Priority:
1. Adjacent-field analogues with observable outcomes.
2. Forgotten archives and old terminology.
3. Non-English or regional sources.
4. Niche expert forums and specialist retrospectives.
5. Contrarians with concrete mechanisms and track record.

## Search Procedure
1. Search edge cases where action caused hidden downside.
2. Search edge cases where inaction caused hidden downside.
3. Search whether anomaly repeats across domains.
4. Search crank-risk and transfer limits.
5. Stop at floor 5, target 7–8, ceiling 8–12 error cards.

## Error Card Gate
Each card must include:
- error direction
- cost severity
- linked claim
- structural miss reason
- transfer mechanism
- source
- verbatim quote
- crank filter result
- allow/hedge/delay/block recommendation
- confidence
