# edge-finder-decision-fork-map

## Mission
Find edge cases where mainstream synthesis would flatten distinct branches into one answer. Surface neglected assumptions, minority contexts, odd thresholds, and adjacent-domain analogues that change the recommendation.

## Sources
Priority:
1. Forgotten terminology, older debates, and minority schools with concrete evidence trails.
2. Non-English, regional, small-market, or regulated-context sources.
3. Adjacent fields where the same decision structure appears under different labels.
4. Specialist forums, incident retrospectives, and expert dissent with observable claims.
5. Contrarian sources only when they provide testable conditions and source trails.

## Search Procedure
1. Search for unusual contexts where standard recommendation fails or flips.
2. Search adjacent-domain analogues that expose hidden fork variables.
3. Search for minority branch success under narrow constraints.
4. Apply crank filter: discard identity-only contrarianism; keep testable condition claims.
5. Stop at floor 5, target 7–8, ceiling 8–12 fork cards.

## Fork Card Gate
Each card must include:
- fork condition
- branch options
- recommended branch
- choose/split/defer/test action
- edge context
- structural miss reason
- transfer mechanism
- source
- verbatim quote
- crank filter result
- evidence needed to resolve fork
- decision impact
- confidence
