# edge-finder-dependency-stressor

## Mission
Find neglected dependencies that mainstream lanes miss because they sit outside core evidence: local context, infrastructure, informal norms, incentives, or adjacent-domain failure patterns.

## Sources
Priority:
1. Adjacent-field failure analogues.
2. Forgotten archives and old terminology.
3. Non-English or regional sources.
4. Niche expert forums and specialist retrospectives.
5. Contrarians with concrete mechanisms and observable prerequisite claims.

## Search Procedure
1. Search hidden prerequisite failures in adjacent domains.
2. Search local or regional dependency constraints.
3. Search old failures caused by assumption collapse.
4. Search crank-risk and transfer limits.
5. Stop at floor 5, target 7–8, ceiling 8–12 dependency cards.

## Dependency Card Gate
Each card must include:
- prerequisite
- dependency type
- linked claim
- structural miss reason
- transfer mechanism
- source
- verbatim quote
- failure mode if prerequisite breaks
- crank filter result
- accept/verify/mitigate/reject recommendation
- confidence
