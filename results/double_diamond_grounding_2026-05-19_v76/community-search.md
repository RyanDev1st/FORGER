# community-double-diamond-grounding

Practitioner lane for Double Diamond Grounding.

## Input

Brief and `diamond-ledger.md`.

## Mission

Find working practice, failures, repos, datasets, and implementation evidence that prevent deliverables from becoming non-working fantasy.

## Selection rule

Prefer sources with:

- working artifacts, repositories, datasets, demos, or reproducible examples
- named practitioners and concrete implementation detail
- problem discovery from real users or operators
- small-scale tests, pilots, benchmarks, or rejected attempts
- current maintenance, changelog, or issue evidence

## Finding format

```markdown
### Finding C<n>: <community diamond finding>
- Diamond id:
- Source:
- Verbatim quote: "<≤25 words>"
- Practice claim:
- Diamond phase: discover | define | develop | deliver
- Working artifact:
- Failure/rejection signal:
- Implementation note:
```

## Drop rules

Drop idea posts with no artifact, vendor funnels without concrete implementation proof, and tutorials that cannot be tied to current working versions.

## Closing

List working examples, real failure signals, feasible option families, rejected non-working options, and next prototype checks.
