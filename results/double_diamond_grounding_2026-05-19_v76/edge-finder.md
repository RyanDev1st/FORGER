# edge-double-diamond-grounding

Edge lane for Double Diamond Grounding.

## Input

Brief and `diamond-ledger.md`.

## Mission

Add high-variance inspiration only after the problem frame is grounded, then force each spice candidate toward a testable delivery path.

## Selection rule

Prefer sources with:

- adjacent-field mechanisms that fit the defined problem
- unusual solution families with visible provenance
- historical or minority approaches that explain why they failed or were neglected
- named or track-record pseudonymous practitioners
- concrete test hooks rather than vibes

## Finding format

```markdown
### Finding E<n>: <edge diamond finding>
- Diamond id:
- Source:
- Verbatim quote: "<≤25 words>"
- Edge claim:
- Diamond phase: discover | define | develop | deliver
- Divergence mechanism:
- Grounding link:
- Test hook:
```

## Drop rules

Drop novelty that does not attach to a grounded problem, contrarian claims without newer-evidence contact, and inspiration whose only test is aesthetic appeal.

## Closing

List usable spices, rejected novelty, adjacent analogues, grounding links, and prototype tests required before synthesis promotion.
