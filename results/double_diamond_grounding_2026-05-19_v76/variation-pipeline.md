# Variation Pipeline — Double Diamond Grounding v76

## Status

v76. Search-first, browser-read, divergence-convergence gated.

## Scope

This variation adds a Double Diamond control loop to reTruth so creative option generation happens after grounded problem discovery and before explicit delivery testing.

## Pipeline

1. Search broad lead pool across academic, practitioner, repository, dataset, forum, and adjacent-field sources.
2. Open candidates directly with `playwright-cli`; record final URL, visible title, and quote.
3. Build `diamond-ledger.md` with source class, browser status, quote, diamond phase, problem signal, option signal, test signal, divergence value, and convergence readiness.
4. Discover: collect problem, user, mechanism, failure, and adjacent inspiration evidence without choosing a solution.
5. Define: cluster source-backed problem frames and drop ungrounded frames.
6. Develop: route option families to Scholar, Community, and Edge for separate evidence-backed development.
7. Deliver: converge only on options with working artifact evidence, test hooks, or explicit prototype path.
8. Preserve rejected options so future runs know which ideas failed and why.

## Audit checks

- Discover precedes Define.
- Define precedes Develop.
- Develop preserves divergent option families.
- Deliver includes tests or rejection reasons.
- Edge spice must attach to source-backed problem evidence.
