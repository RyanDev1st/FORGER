# budget-edge

High-variance lane. Budget prevents weirdness spiral. Spend only where novelty can transfer.

## Phase 1 — Budget allocation

Allocate units across:
1. historical / deprecated term route
2. adjacent-domain route
3. critique / failure route
4. non-English route if useful
5. archive / forum / mailing-list route
6. inversion route
7. minority but credentialed view route

Bias initial units toward routes with plausible transfer and low crank risk.

## Phase 2 — Candidate retrieval

Record:
- source id
- URL
- route family
- source type
- edge reason
- expected value
- likely crank risk
- likely overlap risk

## Phase 3 — Source selection

Keep only sources with:
- audit trail
- extractable quote
- plausible structural transfer
- non-overlap with standard baskets
- clear author or credibility signal

Drop miracle claims, conspiracy framing, hype, anonymous certainty, or quote-free sources.

## Phase 4 — Findings

```markdown
### Finding E<n>: <divergent claim>
- Source id: E<src>
- Source: <title> — <URL>
- Evidence quote: "<verbatim quote>"
- Edge justification: <why other lanes miss it>
- Transfer mechanism: <how it maps back>
- Confidence: <high|medium|low>
- Budget value: <high|medium|low>
- Limits: <what weakens it>
```

## Phase 5 — Budget logic

Edge rebalance rules:
- stop any route after crank risk rises twice
- shift away from fake novelty or redundant sources
- invest extra only when source has clear transfer mechanism
- stop when remaining routes produce weak-signal-only material

Append budget events after each unit.

## Closing

End with:
- findings count
- units spent
- best-yield edge route
- wasted edge unit if any
- unresolved edge claim worth one more unit
- stop reason
