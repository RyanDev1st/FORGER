# gnosis-evidence-compression-index

## Invocation
Use when many findings may create illusion of breadth while actually collapsing to few mechanisms, shared assumptions, repeated datasets, or common provenance trunks.

## Pipeline

### Step 1 — Parse Compression Frame
Extract:
- central claim
- evidence categories expected
- suspected shared mechanisms
- possible common datasets or provenance trunks
- redundancy risk
- independence threshold needed
- decision stakes

### Step 2 — Spawn Lanes
Spawn Scholar, Community, and Edge in parallel. Each lane emits compression cards plus findings.

### Step 3 — Validate
Run V1–V8:
- V1 file exists and non-empty.
- V2 at least 5 compression cards or pivot log.
- V3 no top-level refusal.
- V4 every card has source and verbatim quote.
- V5 every card names evidence trunk or mechanism cluster.
- V6 every card names independence or redundancy result.
- V7 every card recommends count, discount, merge, or re-search.
- V8 closing block present.

### Step 4 — Audit
Check URLs, quote matches, trunk labeling consistency, and Edge redundancy. Preserve failures as downgrade flags.

### Step 5 — Build Compression Index
Classify cards into:
- independent support
- shared dataset trunk
- shared mechanism cluster
- citation echo
- contextual duplicate
- synthetic breadth illusion
- true convergence
- re-search gap

### Step 6 — Synthesize
Return:
- apparent evidence count
- compressed independent count
- main mechanism clusters
- breadth illusion risks
- areas needing new independent evidence

### Step 7 — Re-fan
Re-fan only when compressed count changes recommendation strength. One round max unless user escalates.

## Output
Return:
1. Evidence compression map.
2. Count/discount/merge/re-search decisions.
3. Current synthesis after compression.
4. Breadth illusion hot spots.
5. Independent evidence gaps.
6. Evidence appendix.

## Constraints
- No counting echoed or trunk-shared evidence as independent.
- No independence claim without mechanism, dataset, or provenance reasoning.
- Maximum four concurrent threads.
- Preserve raw evidence appendices.
