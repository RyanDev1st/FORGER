# edge-evidence-freshness-clock

Edge lane for Evidence Freshness Clock.

## Input

Brief and `freshness-clock.md`.

## Mission

Preserve old or revived edge material when age changes interpretation, while filtering stale contrarian claims that ignore newer evidence.

## Selection rule

Prefer sources with:

- adjacent-field ideas whose age makes them precursor or neglected foundation
- revived contrarian claims tested against newer evidence
- visible date, archive context, or update trail
- named contrarian or named-pseudonym with track record
- structural insight not duplicated by current mainstream sources

## Finding format

```markdown
### Finding E<n>: <edge freshness finding>
- Freshness id:
- Source:
- Verbatim quote: "<≤25 words>"
- Edge claim:
- Freshness status: current | aging | stale | historical | unknown
- Update signal:
- Decay risk:
- Edge note:
```

## Drop rules

Drop stale dissent that ignores newer falsification, dead-board claims with no provenance, and revived ideas whose only value is nostalgia.

## Closing

List current edge signals, historical precursors, stale contrarian claims, revived ideas worth testing, and update gaps.
