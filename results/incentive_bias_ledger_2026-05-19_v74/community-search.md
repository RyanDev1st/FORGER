# community-incentive-bias-ledger

Practitioner lane for Incentive Bias Ledger.

## Input

Brief and `incentive-ledger.md`.

## Mission

Assess practitioner evidence through vendor, maintainer, platform, consultancy, and benchmark incentives while preserving useful operational detail.

## Selection rule

Prefer sources with:

- concrete implementation detail despite possible incentive
- disclosed sponsorship, employer, product, or platform role
- independent corroboration from non-vendor practitioners
- benchmark setup transparent enough to inspect
- named practitioners with accountable track record

## Finding format

```markdown
### Finding C<n>: <practice incentive finding>
- Incentive id:
- Source:
- Verbatim quote: "<≤25 words>"
- Practice claim:
- Incentive vector:
- Bias pathway:
- Weight effect: upgrade | neutral | downgrade | exclude
- Practice note:
```

## Drop rules

Drop vendor funnel claims, sponsored benchmarks without setup details, anonymous anecdotes, and maintainer claims that hide breaking-version or environment context.

## Closing

List practitioner claims retained, downgraded, excluded, independent corroboration found, and unresolved incentive gaps.
