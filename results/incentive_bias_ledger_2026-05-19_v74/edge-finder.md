# edge-incentive-bias-ledger

Edge lane for Incentive Bias Ledger.

## Input

Brief and `incentive-ledger.md`.

## Mission

Assess edge evidence through contrarian, audience, reputational, ideological, and outsider incentives without laundering weak dissent into equal status.

## Selection rule

Prefer sources with:

- named contrarian or named-pseudonym with track record
- disclosed stake or visible incentive structure
- grounded adjacent-domain evidence
- independent source trail outside same audience cluster
- clear structural insight despite incentive risk

## Finding format

```markdown
### Finding E<n>: <edge incentive finding>
- Incentive id:
- Source:
- Verbatim quote: "<≤25 words>"
- Edge claim:
- Incentive vector:
- Bias pathway:
- Weight effect: upgrade | neutral | downgrade | exclude
- Edge note:
```

## Drop rules

Drop persecution narratives, audience-capture bait, anonymous allegations, and contrarian claims whose incentive structure explains the whole novelty.

## Closing

List edge claims retained, downgraded, excluded, incentive risks, and structural insights that survive bias scrutiny.
