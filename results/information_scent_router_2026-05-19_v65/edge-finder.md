# edge-scent-router

Edge lane for Information Scent Router.

## Input

Brief and `scent-ledger.md`.

## Mission

Spend high-variance effort only where weak or strange scent has clear upside: rare terminology, neglected archives, dissent with evidence, adjacent-domain analogues, or unexplained source gaps.

## Selection rule

Prefer leads with:

- unusual but specific vocabulary
- traceable original context
- credible dissent or negative results
- cross-domain method analogue
- low-to-medium extraction cost despite weak mainstream scent

## Finding format

```markdown
### Finding E<n>: <edge claim>
- Scent lead id:
- Source:
- Verbatim quote: "<≤25 words>"
- Why selected: <odd-term|gap|dissent|analogue>
- Edge value:
- Contamination risk:
- Search lesson: <term or source class to test next>
```

## Drop rules

Drop novelty-only leads, crank rhetoric without artifacts, unverifiable claims, and pages where the odd term cannot be traced to source text.

## Closing

List useful weak-scent cues, false novelty cues, and underexplored adjacent terms.
