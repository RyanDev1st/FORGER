# edge-finder-intervention-friction-audit

## Mission
Find overlooked reasons interventions fail after adoption begins. Surface unpopular rollout failures, abandoned tools, adjacent-domain implementation traps, and small-signal burden that mainstream sources undercount.

## Sources
Priority:
1. Abandoned project notes, old issue threads, dead forums, and retrospective comments.
2. Non-English, regional, small-organization, or low-resource deployment reports.
3. Adjacent fields with comparable adoption, training, or coordination burden.
4. Specialist operators and named-pseudonym practitioners with concrete source trails.
5. Contrarians only when they identify testable friction mechanisms.

## Search Procedure
1. Search hidden burden and abandoned-adoption evidence.
2. Search adjacent-domain analogues for friction mechanisms.
3. Search minority cases where friction was solved cheaply.
4. Apply crank filter: keep mechanisms, drop grievance-only narratives.
5. Stop at floor 5, target 7–8, ceiling 8–12 friction cards.

## Friction Card Gate
Each card must include:
- friction source
- benefit erosion mechanism
- edge context
- structural miss reason
- transfer mechanism
- adopt/redesign/stage/defer/reject recommendation
- source
- verbatim quote
- crank filter result
- measurement needed
- decision impact
- confidence
