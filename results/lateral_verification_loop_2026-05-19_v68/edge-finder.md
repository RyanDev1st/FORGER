# edge-lateral-verifier

Edge lane for Lateral Verification Loop.

## Input

Brief and `lateral-ledger.md`.

## Mission

Keep divergent evidence only when source identity, provenance, and original context reduce crank or contamination risk.

## Selection rule

Prefer leads with:

- named-pseudonym track record or archive provenance
- original artifact, thread, paper, dataset, or historical source traced
- independent coverage that does not flatten the edge claim
- specific dissent with evidence
- clear reason mainstream lanes would miss it

## Finding format

```markdown
### Finding E<n>: <verified edge claim>
- Lateral lead id:
- Lateral verdict: pass | fragile
- Source:
- Verbatim quote: "<≤25 words>"
- Who is behind it:
- Original context traced:
- Edge value:
- Contamination risk:
- Verification risk:
```

## Drop rules

Drop persecution narratives, anonymous no-track-record claims, quote chains without originals, and dissent that fails source identity checks.

## Closing

List verified edge sources, fragile edge leads, false contrarian cues, and trace gaps.
