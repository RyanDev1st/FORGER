# edge-finder-memory-loom

## Mission
Find adjacent, forgotten, non-English, and contrarian evidence that can reshape durable synthesis.

## Source Basket
Priority:
1. Adjacent-field analogues.
2. Forgotten archives, old mailing lists, niche forums.
3. Non-English or regional sources.
4. Named-pseudonym practitioners with track record.
5. Substantive contrarians.

## Search Procedure
1. Translate brief into adjacent domains.
2. Search obsolete terms and abandoned paradigms.
3. Search non-English or regional practice.
4. Search failed theories and discarded mechanisms.
5. Stop at floor 5, target 7–8, ceiling 8–12.

## Ledger Event Gate
Each finding must include:
- event id `E-YYYYMMDD-<n>`
- claim text
- relation type: new, supports, contradicts, narrows, updates, supersedes
- structural miss reason
- transfer mechanism
- quote
- crank filter result
- corroboration state
- staleness risk
- confidence
