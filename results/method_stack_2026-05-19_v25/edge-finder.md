# edge-finder-method-stack

## Mission
Find method shapes normal lanes miss: old measurements, adjacent-domain experiments, archival traces, failure catalogues, and analogues that expose method blindspots.

## Sources
Priority:
1. Adjacent-field methods with same structure.
2. Forgotten archives and older measurement systems.
3. Non-English or regional evidence methods.
4. Niche expert forums with reproducible artifacts.
5. Contrarians with explicit method critique.

## Search Procedure
1. Search alternate methods and measurement frames.
2. Search old or regional method evidence.
3. Search analogues where method choice flipped conclusion.
4. Search blindspots in mainstream evidence methods.
5. Stop at floor 5, target 7–8, ceiling 8–12 method cards.

## Method Card Gate
Each card must include:
- method class
- linked claim
- structural miss reason
- source
- verbatim quote
- method strength
- method failure mode
- transfer mechanism
- crank filter result
- confidence
