# community-need-to-knowledge-broker

Practitioner lane for Need-to-Knowledge Broker.

## Input

Brief and `ntk-ledger.md`.

## Mission

Find working implementations, stakeholder constraints, market/practice signals, and transfer paths that show whether knowledge can move into use.

## Selection rule

Prefer sources with:

- working prototypes, repos, datasets, patents, demos, or maintained tools
- user/operator pain points and concrete functional needs
- issue threads, changelogs, benchmarks, or adoption evidence
- named stakeholders and practical constraints
- evidence of implementation, transfer, maintenance, or failure

## Finding format

```markdown
### Finding C<n>: <community NtK finding>
- NtK id:
- Source:
- Verbatim quote: "<≤25 words>"
- Practice claim:
- NtK phase: need | existing-knowledge | invention | development | implementation | impact
- Working artifact:
- Stakeholder signal:
- Transfer path:
```

## Drop rules

Drop solution-first posts, unmaintained artifacts without lesson value, vendor claims without working evidence, and demos not tied to user need.

## Closing

List functional needs, reusable artifacts, stakeholder constraints, transfer-ready practices, failed transfer paths, and adoption gaps.
