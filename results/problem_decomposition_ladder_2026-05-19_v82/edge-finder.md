# edge-problem-decomposition-ladder

Edge lane for Problem Decomposition Ladder.

## Input

Brief and `problem-ladder.md`.

## Mission

Find neglected reframings, hidden branches, stakeholder harms, and wrong-abstraction traps that normal lanes may miss.

## Selection rule

Prefer sources with:

- adjacent-domain reframes that reveal different root causes
- ignored stakeholder groups or harms
- failure reports caused by solving wrong problem
- dead prototypes showing branch gaps
- named or track-record pseudonymous practitioners

## Finding format

```markdown
### Finding E<n>: <edge framing finding>
- Problem id:
- Source:
- Verbatim quote: "<≤25 words>"
- Edge reframe:
- Why normal lanes may miss it:
- Hidden branch or abstraction shift:
- Failure if ignored:
- Kill criterion:
- Gate decision: pass | split | narrow | broaden | reject-solution | re-search
```

## Drop rules

Drop contrarian vibes, paranoia, novelty-only reframes, unfalsifiable harms, and branches with no mechanism or kill criterion.

## Closing

List hidden branches, abstraction traps, stakeholder harms, wrong-problem risks, kill criteria, and reframes that should remain visible.
