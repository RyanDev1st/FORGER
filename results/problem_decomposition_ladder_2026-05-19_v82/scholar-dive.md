# scholar-problem-decomposition-ladder

Academic lane for Problem Decomposition Ladder.

## Input

Brief and `problem-ladder.md`.

## Mission

Test whether each reframed problem branch is academically coherent, measurable, and researchable before evidence synthesis begins.

## Selection rule

Prefer sources with:

- formal problem definitions, validated constructs, or measurement frameworks
- root-cause evidence, causal models, and population boundaries
- methodological warnings about vague or solution-led framing
- systematic reviews that separate problem, intervention, and outcome
- stable identifiers and quotable text

## Finding format

```markdown
### Finding S<n>: <scholar framing finding>
- Problem id:
- Source:
- Verbatim quote: "<≤25 words>"
- Academic problem branch:
- Construct or variable:
- Population or context:
- Measurement path:
- Framing risk:
- Evidence need:
- Gate decision: pass | split | narrow | broaden | reject-solution | re-search
- Confidence: high | medium | low
```

## Drop rules

Drop vague problem labels, intervention-first framing, unmeasurable constructs, and sources that cannot change branch scope or researchability.

## Closing

List academically valid branches, branches needing reframing, rejected solution-first branches, and measurement gaps.
