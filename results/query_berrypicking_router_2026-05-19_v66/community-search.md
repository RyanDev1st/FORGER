# community-berry-router

Practitioner lane for Query Berrypicking Router.

## Input

Brief and `berry-ledger.md`.

## Mission

Follow browser-read artifact, failure, repo, benchmark, migration, and named-practitioner branches toward usable field evidence.

## Selection rule

Prefer branches with:

- repo, issue, benchmark, dataset, or postmortem hook
- named engineer, maintainer, or team
- concrete failure or migration vocabulary
- implementation nouns from source text
- low extraction cost and clear quote support

## Finding format

```markdown
### Finding C<n>: <practice claim>
- Berry lead id:
- Query branch:
- Source:
- Verbatim quote: "<≤25 words>"
- Branch origin: <artifact|failure term|practitioner name>
- Practice implication:
- Adoption risk:
- Next berry: <query/artifact to follow>
```

## Drop rules

Drop marketing branches, generic tutorial vocabulary, anonymous anecdote chains, and pages where artifact names are visible only in snippets.

## Closing

List highest-yield practitioner terms, false artifact hooks, and field vocabulary to reuse.
