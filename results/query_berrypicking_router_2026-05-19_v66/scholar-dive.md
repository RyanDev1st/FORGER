# scholar-berry-router

Academic lane for Query Berrypicking Router.

## Input

Brief and `berry-ledger.md`.

## Mission

Follow browser-read citation, method, and controlled-vocabulary branches toward citable evidence.

## Selection rule

Prefer branches with:

- named theory, method, or author
- citation trail or bibliography hook
- systematic-review vocabulary
- clear study design terms
- corroboration across institutional sources

## Finding format

```markdown
### Finding S<n>: <method claim>
- Berry lead id:
- Query branch:
- Source:
- Verbatim quote: "<≤25 words>"
- Branch origin: <quote term|citation hook|method term>
- Claim:
- Confidence:
- Next berry: <follow-up query/citation>
```

## Drop rules

Drop branches born from snippets only, unsourced citation names, inaccessible papers with no extractable abstract, and method terms with no corroboration route.

## Closing

List best academic branch terms, dead citation trails, and vocabulary that should replace seed terms.
