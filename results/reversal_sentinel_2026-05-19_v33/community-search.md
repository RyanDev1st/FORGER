# community-search-reversal-sentinel

## Mission
Find practical evidence where accepted advice reversed after production contact, scale, incentives, or ecosystem changes.

## Sources
Priority:
1. Postmortems, incident reviews, migration retrospectives.
2. Maintainer issues, RFC reversals, changelogs, and design rollbacks.
3. Production case studies, repos, benchmarks, and datasets over time.
4. Practitioner debates with named expertise and timestamped shifts.

## Search Procedure
1. Search current practical consensus.
2. Search old best practices now rejected.
3. Search deployment incidents that reversed recommendations.
4. Search scale, cost, incentive, and maintenance triggers.
5. Stop at floor 5, target 8–10, ceiling 12–15 reversal cards.

## Reversal Card Gate
Each card must include:
- reversal direction
- reversal mechanism
- linked operational claim
- authority signal
- firsthand status
- source
- verbatim quote
- chronology
- trust/hedge/test/reject recommendation
- decision impact
- confidence
