# edge-search-provenance-spine

Edge lane for Search Provenance Spine.

## Input

Brief and `provenance-spine.md`.

## Mission

Preserve auditable edge search path so adjacent-domain, contrarian, and anomalous routes can be judged by provenance rather than novelty alone.

## Selection rule

Prefer provenance steps with:

- surprising but traceable route changes
- adjacent-domain or archive discoveries
- named contrarian with track record
- source mismatches or provenance anomalies worth exposing
- visible reason edge route differed from scholar/community path

## Finding format

```markdown
### Finding E<n>: <edge finding with provenance>
- Provenance step id:
- Source:
- Verbatim quote: "<≤25 words>"
- Edge claim:
- Search-path effect:
- Better-supported side: source | route | neither | depends
- Repro note:
```

## Drop rules

Drop provenance notes built on anonymous fringe retellings, persecution narratives, or novelty with no reconstructable route.

## Closing

List edge findings, anomalous but meaningful provenance turns, blocked or mismatched fringe paths, and why provenance mattered.
