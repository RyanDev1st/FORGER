# scholar-search-provenance-spine

Academic lane for Search Provenance Spine.

## Input

Brief and `provenance-spine.md`.

## Mission

Preserve auditable academic search path so study findings stay linked to query choices, evidence-quality routing, and exclusions.

## Selection rule

Prefer provenance steps with:

- database or review-search decisions that changed evidence set
- included versus excluded study boundaries
- source-quality reroutes
- reference-list or citation-search expansions
- strong quote support from original or high-authority synthesis sources

## Finding format

```markdown
### Finding S<n>: <scholarly finding with provenance>
- Provenance step id:
- Source:
- Verbatim quote: "<≤25 words>"
- Claim:
- Search-path effect:
- Better-supported side: source | route | depends
- Repro note:
```

## Drop rules

Drop provenance notes with no visible effect on evidence set, abstract-only steps, and unclear exclusions that cannot be linked to actual source handling.

## Closing

List academic findings, decisive provenance steps, exclusion patterns, and where scholarly reproducibility still breaks.
