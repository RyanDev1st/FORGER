# edge-finder-threshold-finder

## Mission
Find threshold effects normal lanes miss: nonlinear breaks, hidden constraints, old scaling limits, adjacent-domain tipping points, and regional boundary conditions.

## Sources
Priority:
1. Adjacent-field analogues with known threshold behavior.
2. Forgotten archives and historical failure limits.
3. Non-English or regional sources with different constraints.
4. Niche expert forums and specialist benchmarks.
5. Contrarians with measurable threshold claims.

## Search Procedure
1. Search nonlinear and tipping-point language.
2. Search hidden constraints mainstream summaries ignore.
3. Search old or regional threshold cases.
4. Search adjacent domains where same variable flips outcome.
5. Stop at floor 5, target 7–8, ceiling 8–12 threshold cards.

## Threshold Card Gate
Each card must include:
- variable
- threshold direction
- linked claim
- decision effect
- structural miss reason
- transfer mechanism
- source
- verbatim quote
- crank filter result
- confidence
