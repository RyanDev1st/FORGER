# edge-confidence-matrix

Edge lane for Triangulation Confidence Matrix.

## Input

Brief and `confidence-matrix.md`.

## Mission

Keep exploratory and analogical evidence useful without letting it contaminate robust consensus.

## Selection rule

Prefer claims with:

- explicit exploratory or analogue tier
- independent provenance or track record
- source diversity outside normal lane baskets
- clear structural reason mainstream lanes miss it
- contamination risk that can be named

## Finding format

```markdown
### Finding E<n>: <confidence-rated edge claim>
- Matrix claim id:
- Confidence tier: exploratory | fragile | supported
- Source:
- Verbatim quote: "<≤25 words>"
- Source diversity:
- Independence:
- Bias risk:
- Edge value:
- Contamination risk:
```

## Drop rules

Drop edge claims that pretend exploratory evidence is robust, same-community echo claims, untraceable contrarian claims, and high-bias claims in harm domains.

## Closing

List exploratory signals, supported edge claims, contamination risks, and claims blocked from robust synthesis.
